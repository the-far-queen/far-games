# sources — public-domain game assets + mechanics

Public-domain sources far-games draws from for the `source_id` axis
(AGENTS.md). Every mechanic must trace back to one of these.

## primary sources

### opengameart.org — CC0 + CC-BY art
- **url:** https://opengameart.org/
- **license:** CC0, CC-BY, CC-BY-SA (filter for your needs)
- **what we get:** sprites, tiles, characters, UI, sounds, music
- **notes:** filter by license = CC0 for cleanest reuse

### kenney.nl — public-domain game assets
- **url:** https://kenney.nl/
- **license:** CC0
- **what we get:** platformer, top-down, UI, isometric packs
- **notes:** the canonical free asset source. most packs are CC0.

### libtcod + bearLibTerminal — roguelike toolkits
- **url:** https://libtcod.github.io/
- **license:** various (BSD/MIT for code)
- **what we get:** roguelike scaffolding
- **notes:** source code CC0 for many tutorials

### gnu games — open-source game repos
- **url:** https://directory.fsf.org/wiki/Games
- **license:** mostly GPL (verify per repo)
- **what we get:** complete games + source

### freegamedev wiki — CC0 + open-source games
- **url:** https://freegamedev.net/
- **license:** varies
- **what we get:** smaller indie games + assets

## secondary sources

- **itch.io devlog free assets** — community-contributed
- **opengameart forums** — announcements + collaboration
- **github** — search `license:cc0 OR license:mit game`
